# Domain docs

Before exploring, read the root `CONTEXT.md` and relevant records in `docs/adr/`.
If they do not exist, proceed silently. Create them lazily when terms or durable
architectural decisions are resolved.

This repository uses a single domain context.

Use terms from `CONTEXT.md` consistently in code, tests, specs, and tickets.
Surface conflicts with existing ADRs instead of silently overriding them.
