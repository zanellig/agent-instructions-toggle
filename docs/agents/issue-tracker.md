# Issue tracker: GitHub

Issues and specs live in GitHub Issues. Use the `gh` CLI from this repository.

## Conventions

- Create, read, comment on, label, and close issues with `gh issue`.
- Infer the repository from the configured `origin` remote.
- Pull requests are not a request or triage surface.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- Read referenced issues with their full body, comments, and labels.
- Use GitHub native issue dependencies for blocking edges.
- Use textual `Blocked by` references only if native dependencies are unavailable.
